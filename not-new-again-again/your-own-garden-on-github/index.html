Your own garden on GitHub

516 words

This puts the public notes from your Smart Journal vault on a website of your own, at https://YOUR-USERNAME.github.io/garden/. It takes about 15 minutes the first time and about 3 minutes to update later. Everything is free.

Before you start

  • A free GitHub account — sign up at github.com if you don't have one.

  • In Smart Journal, a public vault holding the notes you want to share. Private vaults can never be published or exported. To make one: sidebar → vault switcher → New vault → Public.

  • A computer with Chrome, Edge or Firefox. Uploading folders to GitHub doesn't work from a phone.

Step 1 — Create the repository

  1. Sign in at github.com, click + at the top right → New repository.

  2. Repository name: garden. Any name works; it becomes the last part of your site's address.

  3. Choose Public. Free GitHub accounts can only host sites from public repositories.

  4. Tick Add a README file, so the repository isn't empty.

  5. Click Create repository.

Step 2 — Turn on GitHub Pages

  1. In your new repository, open Settings → Pages (left sidebar).

  2. Under Build and deployment, set Source to Deploy from a branch.

  3. Set Branch to main and the folder to / (root), then click Save.

After your first upload (Step 4), this page shows your site's address: https://YOUR-USERNAME.github.io/garden/.

Step 3 — Export your vault from Smart Journal

  1. Open Smart Journal and switch to your public vault.

  2. Click the 🌐 button at the top right. This opens the review of what will go public.

  3. Check the list. Notes you've held back (the crossed-out eye in a note's header) are left out, and links to them become plain text.

  4. Click Zip — not Publish, which sends the vault to Amogh's shared garden instead. A .zip file downloads.

  5. Unzip it: double-click it on a Mac, or right-click → Extract All on Windows. You get a folder containing index.html, style.css, script.js, README.md and a folder named after your vault.

Step 4 — Upload it to your repository

  1. In your repository on GitHub, click Add file → Upload files.

  2. Open the unzipped folder, select everything inside it (the files and the vault folder, not the outer folder itself) and drag it onto the GitHub page.

  3. Wait until every file is listed, then click Commit changes.

  4. After a minute or two, open https://YOUR-USERNAME.github.io/garden/. Your vault is live.

GitHub's upload page takes at most 100 files at a time, and each note is one file. If your vault has more than about 95 notes, upload the note folders in two rounds and commit after each, or use the free GitHub Desktop app.

Updating your site later

  1. Export again (Step 3).

  2. Upload again (Step 4). Files with the same name are replaced.

  3. A note you deleted, renamed or held back keeps its old page online until you remove it on GitHub: open its folder in the repository → ⋯ → Delete directory, then commit.

Good to know

  • Everything in the repository is public, including the history of every upload.

  • Links between your notes work as they do in the app, each page lists the notes that link to it, and readers get light and dark mode.

  • You can use your own domain later: Settings → Pages → Custom domain.

  • Stuck? Send Amogh a screenshot of the step you're on.
